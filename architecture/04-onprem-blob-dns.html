How on-premises resolves Blob across three Azure regions

One on-premises DNS server. Two regional Azure Private Resolvers over site-to-site VPN. One shared global Private DNS zone.

Legend: Solid = site-to-site VPN carrying the DNS query and reply. Dashed = VNet link granting zone visibility, not a packet path. Highlighted Blob card = matching DNS record.

    DNS is not connectivity. After the lookup, the client opens a separate HTTPS connection to the returned private IP. Sweden does not need a resolver for this lookup. Reaching the Sweden private endpoint in this design requires the West Europe–Sweden Global VNet Peering path with verified gateway transit and return routing, or another supported path.
